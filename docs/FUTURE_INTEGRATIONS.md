# Integrações futuras

Mapas reais, telemetria, emissão fiscal, documentos oficiais, anexos em Storage, instrutor multiusuário, certificação com validação autoritativa, e autenticação por telefone são evoluções fora do escopo atual. Serviços cobrados exigem aprovação explícita. Não habilitar Blaze automaticamente. A primeira versão usa apenas SDK Firebase Web e hospedagem estática.
